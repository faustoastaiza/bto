# BTO Constructora — Sitio web

Sitio institucional de BTO Constructora — la alianza entre **Only Home** y el arquitecto **Juan Carlos Jaramillo** en el Eje Cafetero.

## Estructura

- `index.html` — Home
- `nosotros.html` — Equipo, origen, principios, aliados
- `proyectos.html` — Listado de proyectos
- `proyectos/garden-houses.html` — Armenia
- `proyectos/indigo-mall.html` — Dosquebradas
- `proyectos/indigo-houses.html` — Dosquebradas
- `proyectos/indigo-park.html` — Ecosistema Índigo
- `proyectos/indigo-towers.html` — Próximamente
- `assets/css/style.css` — Sistema de diseño (B&N + glassmorphism)
- `assets/js/main.js` — Navegación y animaciones
- `assets/img/` — Imágenes (brand, proyectos, equipo)
- `assets/video/` — Video hero

## Tecnologías

HTML + CSS + JavaScript estático. Sin build step.

## Cómo correrlo localmente

```bash
python3 -m http.server 8000
# o
npx serve .
```

Abrir `http://localhost:8000`.
